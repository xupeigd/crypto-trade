# 交易风控订单审核系统设计文档

## 一、需求细化

### 1. 核心业务需求

- **风控模式**：当风控模式为`MANUAL`（手动模式）时，所有订单100%进入风控审核流程
- **审核机制**：简单的用户确认即可，无需复杂的权限验证
- **审核结果**：
    - **通过**：触发CEX接口下单交易
    - **驳回**：不触发CEX接口，订单状态标记为已驳回

### 2. 功能需求细化

#### 2.1 订单拦截与风控判断

- **集成点**：在`TradingOrderService.placeOrder()`方法中增加风控判断
- **判断逻辑**：
  ```java
  if (aiTradingRiskControlConfig.isManualMode()) {
      // 进入风控审核流程
      createRiskControlOrder(orderRequest);
      return; // 不直接调用CEX接口
  }
  // 原有的直接下单流程
  ```

#### 2.2 风控审核数据结构

- **原始订单数据**：完整保存用户提交的订单信息
- **风控等级**：根据当前交易风格自动设置（C1_CONSERVATIVE/C2_CAUTIOUS→HIGH，C3_MODERATE→MEDIUM，C4_ACTIVE/C5_AGGRESSIVE→LOW）
- **审核状态**：PENDING（待审核）、APPROVED（已通过）、REJECTED（已驳回）

#### 2.3 审核界面需求

- **位置**：OKX交易页面右侧10%空间
- **列表展示**：显示待审核订单的关键信息
- **操作按钮**：审核、驳回
- **订单详情**：点击可查看完整订单信息

### 3. 技术需求细化

#### 3.1 数据库设计

- **表名**：`t_risk_control_orders`
- **关键字段**：
    - `order_id`：主键，自增
    - `original_order_id`：原始订单ID（UUID或业务ID）
    - `api_key_id`：API Key ID
    - `order_data`：JSON格式存储完整订单信息
    - `audit_status`：审核状态
    - `audit_user`：审核人（当前可为"system"或用户名）
    - `audit_time`：审核时间
    - `rejection_reason`：驳回原因
    - `risk_level`：风控等级
    - `create_time`：创建时间
    - `update_time`：更新时间

#### 3.2 状态流转设计

```
PENDING → APPROVED → 触发CEX下单
PENDING → REJECTED → 订单结束
```

#### 2.3 服务类设计

```java

@Service
@Slf4j
public class RiskControlOrderService {

    @Autowired
    private RiskControlOrderRepository riskControlOrderRepository;

    @Autowired
    private AiTradingRiskControlConfig riskControlConfig;

    @Autowired
    private TradingOrderService tradingOrderService;

    /**
     * 创建风控审核订单
     */
    @Transactional
    public RiskControlOrder createRiskOrder(OrderRequest orderRequest) {
        log.debug("创建风控审核订单: {}", orderRequest);

        // 1. 生成唯一订单ID
        String originalOrderId = UUID.randomUUID().toString();

        // 2. 根据交易风格设置风控等级
        RiskLevel riskLevel = determineRiskLevel(riskControlConfig.getCurrentTradingStyle());

        // 3. 创建风控订单
        RiskControlOrder riskOrder = new RiskControlOrder(
                originalOrderId,
                orderRequest.getApiKeyId(),
                orderRequest.getInstId(),
                OrderType.valueOf(orderRequest.getOrderType().toUpperCase()),
                OrderSide.valueOf(orderRequest.getSide().toUpperCase()),
                orderRequest.getSz(),
                orderRequest.getPx(),
                "okx_trading",
                riskLevel
        );

        // 4. 保存到数据库
        riskControlOrderRepository.save(riskOrder);

        log.debug("风控审核订单创建成功: orderId={}, riskLevel={}",
                riskOrder.getOrderId(), riskLevel);

        return riskOrder;
    }

    /**
     * 审核通过订单
     */
    @Transactional
    public void approveOrder(Long riskOrderId, String auditUser) {
        log.debug("审核通过风控订单: orderId={}, auditor={}", riskOrderId, auditUser);

        // 1. 查询风控订单
        RiskControlOrder riskOrder = riskControlOrderRepository.findById(riskOrderId)
                .orElseThrow(() -> new BusinessException("风控订单不存在"));

        if (riskOrder.getAuditStatus() != AuditStatus.PENDING) {
            throw new BusinessException("订单状态不是待审核状态");
        }

        // 2. 更新审核状态
        riskOrder.approve(auditUser);
        riskControlOrderRepository.save(riskOrder);

        // 3. 构建原始订单请求并执行实际下单
        OrderRequest orderRequest = rebuildOrderRequest(riskOrder);
        tradingOrderService.placeOrder(orderRequest);

        log.info("风控订单审核通过并执行下单: orderId={}", riskOrderId);
    }

    /**
     * 驳回订单
     */
    @Transactional
    public void rejectOrder(Long riskOrderId, String auditUser, String reason) {
        log.info("驳回风控订单: orderId={}, auditor={}, reason={}", riskOrderId, auditUser, reason);

        RiskControlOrder riskOrder = riskControlOrderRepository.findById(riskOrderId)
                .orElseThrow(() -> new BusinessException("风控订单不存在"));

        if (riskOrder.getAuditStatus() != AuditStatus.PENDING) {
            throw new BusinessException("订单状态不是待审核状态");
        }

        // 更新审核状态和驳回原因
        riskOrder.reject(auditUser, reason);
        riskControlOrderRepository.save(riskOrder);

        log.info("风控订单已驳回: orderId={}", riskOrderId);
    }

    /**
     * 获取待审核订单列表
     */
    public List<RiskControlOrder> getPendingOrders() {
        return riskControlOrderRepository.findByAuditStatusOrderByCreateTimeDesc(AuditStatus.PENDING);
    }

    /**
     * 根据交易风格确定风控等级
     *
     * @param tradingStyle 交易风格
     * @return 风控等级
     */
    private RiskLevel determineRiskLevel(TradingStyle tradingStyle) {
        switch (tradingStyle) {
            case C1_CONSERVATIVE:
            case C2_CAUTIOUS:
                return RiskLevel.HIGH;
            case C3_MODERATE:
                return RiskLevel.MEDIUM;
            case C4_ACTIVE:
            case C5_AGGRESSIVE:
                return RiskLevel.LOW;
            default:
                return RiskLevel.MEDIUM;
        }
    }

    /**
     * 从风控订单重建原始订单请求
     */
    private OrderRequest rebuildOrderRequest(RiskControlOrder riskOrder) {
        OrderRequest orderRequest = new OrderRequest();
        orderRequest.setApiKeyId(riskOrder.getApiKeyId());
        orderRequest.setInstId(riskOrder.getSymbol());
        orderRequest.setOrderType(riskOrder.getOrderType().name().toLowerCase());
        orderRequest.setSide(riskOrder.getSide().name().toLowerCase());
        orderRequest.setSz(riskOrder.getQuantity());
        orderRequest.setPx(riskOrder.getPrice());
        // 设置其他必要的字段...
        return orderRequest;
    }
}
```

```java
@RestController
@RequestMapping("/risk-control")
@Slf4j
public class RiskControlOrderController {

    @Autowired
    private RiskControlOrderService riskControlOrderService;
    @Autowired
    private RiskControlService riskControlService;

    /**
     * 获取待审核订单列表
     */
    @GetMapping("/orders/pending")
    public ApiResponse<List<RiskControlOrderModel>> getPendingOrders() {
        List<RiskControlOrder> orders = riskControlOrderService.getPendingOrders();
        return ApiResponse.ok(orders.stream().map(this::toModel).collect(Collectors.toList()));
    }

    /**
     * 审核通过订单
     */
    @PostMapping("/orders/{orderId}/approve")
    public ApiResponse<Void> approveOrder(@PathVariable Long orderId) {
        riskControlOrderService.approveOrder(orderId, "system");
        return ApiResponse.ok(null);
    }

    /**
     * 驳回订单
     */
    @PostMapping("/orders/{orderId}/reject")
    public ApiResponse<Void> rejectOrder(
            @PathVariable Long orderId,
            @RequestBody Map<String, String> request) {
        String reason = request.getOrDefault("reason", "无驳回原因");
        riskControlOrderService.rejectOrder(orderId, "system", reason);
        return ApiResponse.ok(null);
    }

    /**
     * 获取当前风控模式
     */
    @GetMapping("/orders/current-mode")
    public ApiResponse<CurrentModeResponse> getCurrentMode() {
        RiskMode currentMode = riskControlService.getCurrentMode();
        return ApiResponse.ok(CurrentModeResponse.fromRiskMode(currentMode));
    }

    /**
     * 根据actionId查询风控订单
     */
    @GetMapping("/orders/by-action-id/{actionId}")

        RiskControlOrderModel order = riskControlOrderService.getOrderByActionId(actionId);

     * 根据recordId查询所有关联的风控订单
```

### 2. 风控等级映射

```java
public RiskLevel determineRiskLevel(TradingStyle tradingStyle) {
    switch (tradingStyle) {
        case C1_CONSERVATIVE:
        case C2_CAUTIOUS:
            return RiskLevel.HIGH;    // 保守型/谨慎型→高风险
        case C3_MODERATE:
            return RiskLevel.MEDIUM;  // 稳健型→中风险
        case C4_ACTIVE:
        case C5_AGGRESSIVE:
            return RiskLevel.LOW;     // 积极型/激进型→低风险
        default:
            return RiskLevel.MEDIUM;  // 默认中风险
    }
}
```
