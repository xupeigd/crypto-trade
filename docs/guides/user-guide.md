# Crypto Trade System - 用户指南

本指南帮助您快速上手系统。

---

## 快速开始

完成以下 3 步即可开始交易：

### 步骤 1: 配置大模型

1. 访问 **系统设置 → 大模型配置**（`/system/ai-model-configs`）
2. 点击「新增模型」
3. 根据模型类型，填写模型信息：
   - **本地模型 (LOCAL)**: 使用 Ollama，需填写本地地址 `http://localhost:11434`
   - **远端模型 (REMOTE)**: 使用 Deepseek/OpenAI 等，需填写 API 地址和密钥
4. 点击「保存」，保存大模型配置
5. 在AI模型配置管理列表，点击「测试连接」测试大模型是否可用。
6. 在AI模型配置管理列表，点击「设为默认」，将大模型设置为默认。

### 步骤 2: 添加交易所 API Key

1. 访问 **系统设置 → CEX API Key 管理**（`/system/cex-keys`）
2. 点击「新建API Key」
3. 选择交易所（本版本暂时只支持OKX）
4. 填写 Access Key、Secret Key、Pass Phrase
5. 选择存储方式：
   - **DB**: 加密存入数据库（方便）
   - **ENV**: 环境变量引用（更安全）
6. 选择交易类型 实盘/模拟盘
7. 点击「创建」，保存API配置（⚠️ AI交易不支持选择api key，会使用第一个活跃状态的api key进行交易，手动交易支持选择api Key进行交易）。

### 步骤 3: 开始交易

#### 方式 A: 手动交易
1. 访问 **合约交易**（`/trading`）
2. 选择交易品种、API Key、订单类型
3. 设置金额、杠杆、止盈止损
4. 点击「开多」或「开空」

#### 方式 B: BOT 自动交易
1. 访问 **BOT 交易**（`/bot`）
2. 选择 API Key 和 AI 模型
3. 点击「直接触发 BOT」
4. AI 将分析市场并执行交易

## 常见问题

**Q: 如何判断配置成功？**
A: 大模型使用「测试连接」验证；API Key 可尝试查询账户余额验证。

**Q: 实盘和模拟盘有什么区别？**
A: 模拟盘使用测试网络，不真实资金；实盘使用真实资金交易。事实上，很多交易所的实盘和模拟盘key是隔离的。

**Q: BOT 不执行交易怎么办？**
A: 检查 API Key 是否启用、风控模式设置、AI 决策结果可能为 HOLD。

**Q: 如何查看 BOT 决策逻辑？**
A: 在 BOT 页面点击「查看会话链路」可查看完整决策过程。
